プライバシーポリシー

就活監視ヘッダー確認（Job Monitor Headers）は、運営者本人のメールの概要を確認するための個人用アプリです。本ポリシーは、本アプリとその説明サイトにおける情報の取扱いを説明します。

1. 運営者と利用目的

運営者は takagakiyuki2003-debug です。本人が指定したメールのメタデータを取得し、就職活動に関する情報の確認・整理と、取得元の照合に利用します。第三者のGoogleアカウントを対象としたサービスは提供していません。

2. 取得する情報

Googleの認証を経て、Gmail APIの gmail.metadata 権限を使用します。取得対象には次の情報が含まれます。

  • 送信元（From・Sender）、件名（Subject）、メールヘッダーの日時（Date）、Message-ID。
  • GmailのメッセージID、スレッドID、履歴ID、受信日時、ラベルID。
  • 接続先の確認に用いるGoogleアカウントのメールアドレス。
  • 接続の維持に必要なOAuth認証情報、およびエラーコードや実行時刻などの接続診断情報。

メール本文、プレビュー（snippet）、添付ファイルは取得しません。メールの送信、削除、既読化、ラベル変更は行いません。

3. 処理と外部サービスへの送信

メタデータは本人のPCで取得され、中継接続を通じてOpenAIのChatGPT/Codexに送られます。送信は、本人が依頼した確認結果の表示・整理のために行います。中継を提供するサービスも、この通信の処理に関わります。

OAuth認証情報はGoogleとの認証に使用します。メール確認ツールの回答や、この公開サイトには掲載しません。

本アプリを通じたGoogleデータの取扱いは、Google API Services User Data Policy（Limited Useの要件を含む）に従い、本人に示した確認・整理の目的に限定します。運営者は、Googleデータを販売したり、広告配信に利用したりしません。

4. 保存と保持

継続接続に必要な認証情報は、本人のWindows PC上でWindowsの暗号化機能を使用して保存します。取得したメタデータは処理中に使用され、返却先の会話履歴やツール実行履歴に残る場合があります。接続状態・診断情報はPC側の運用記録に残る場合があります。

本人の承認により確認結果を別の台帳やファイルへ保存する場合、その保存先でも保持されます。Gmailヘッダー取得ツール自体はGoogle Sheetsへの書き込み機能を持ちません。

本アプリには、外部サービスの会話履歴や別途保存された台帳を一括で自動削除する機能はありません。保持期間は、本人の削除操作と各保存先の設定・規約に従います。OpenAIや中継サービスによる取扱いには、それぞれのサービスのポリシーと利用設定も適用されます。

5. 利用停止と削除

本人はPC中継の利用を停止し、Googleアカウントで本アプリへのアクセス許可を取り消すことができます。アクセス許可の取消しと、既に保存された情報の削除は別の操作です。

不要になったPC上の認証情報・診断記録、外部サービスの会話履歴、本人が保存した台帳などは、それぞれの保存先で削除します。削除については下記の連絡先へ問い合わせることもできます。

6. この説明サイト

このサイトには、Googleログイン、メール情報の入力フォーム、アクセス解析タグ、広告、独自のCookie保存処理を設置していません。GitHub Pagesで公開された場合、配信元のGitHubがアクセス時のIPアドレスなどを処理することがあります。詳細はGitHubのプライバシー声明をご覧ください。

7. 変更と連絡先

取得項目や利用目的を変更する場合、本ポリシーとアプリの説明を更新し、必要な同意を得てから変更後の取扱いを開始します。
